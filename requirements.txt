# Rialto backend — runtime dependencies: NONE.
#
# The server is deliberately standard-library only (http.server, urllib,
# html.parser, xml.etree, concurrent.futures, email.utils). Everything it
# needs ships with Python 3.12+; nothing to install, nothing to pin, nothing
# to audit for supply-chain risk on a box that never talks to the internet
# except to fetch public feeds.
#
# Project metadata and the `rialto` console script live in pyproject.toml:
#   pip install -e .     (optional — plain `python3 server.py` works too)
